# Changelog

## 0.3.0 · 2026-10-26
- Nueva identidad: logo de Stream Deck en pixel art y banners para GitHub. Al iniciar, el deck "se enciende".
- Un solo `SBDeck.bat`: instala todo la primera vez (incluido Python con winget si falta) y después solo abre.
- Fondo mate con malla técnica y paneles mate.
- Nuevo modo **Tareas**, guardadas en la PC (reemplaza a Pantalla).
- Espectro de audio con PyAudioWPatch (loopback WASAPI) y aviso de error en pantalla.
- Portadas de música: reintentos cuando el navegador las manda tarde.
- Botón de monitores: deja el monitor principal de Windows (o `solo:N`) usando MultiMonitorTool.
- Configuración desde el navegador de la PC (doble clic en la bandeja).
- Actualizaciones automáticas con `git pull`; la tablet se recarga sola.
- Se abre solo con Windows desde la primera vez.
- Ajustes → Estado de la PC.

## 0.2.0 · 2026-10-25
